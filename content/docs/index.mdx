Wax lets you write mods for ICARUS in Lua.

A mod is a folder with one file in it, called `init.lua`. Wax runs that file inside the game.

This is an early version. The download is on the [Installing](/docs/install) page.

## What a mod looks like

This is a whole mod. It makes a window with one button.

```lua title="init.lua"
local window = ui.Window({ title = "Hello" })

window:Button("Say hi", function()
    ui.Notify("Hi from my mod!")
end)
```

Press **F8** in the game and the window is there. Click the button and a message shows in a corner of the screen.

## What you can do

- Read and change the game's objects. Start at `game` and go to the world, the player and every other object. See [The game tree](/docs/game).
- Make an interface with windows, buttons, switches, sliders, lists, overlays and notifications. See [Controls](/docs/gui/controls).
- Run code over time. Wait, repeat and delay without freezing the game. See [Tasks](/docs/tasks).
- Run a function when something happens, such as a map change or a flipped switch. See [Signals](/docs/signals).
- Keep settings between game sessions. See [Saving settings](/docs/storage).

## What Wax does for you

- When you save a file, the mod reloads in the running game. You don't restart anything. See [Hot reload](/docs/hot-reload).
- One key opens every mod's windows. See [The menu](/docs/menu).
- A panel in the game lists your mods, shows the log and runs a line of Lua. See [The Wax panel](/docs/debug-panel).
- Wax catches an error in your mod. The error shows as a notification and in the log, with the line it happened on.
- Everything your mod makes is removed when the mod reloads. You don't write clean-up code.
