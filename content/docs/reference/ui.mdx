## Named values [#named-values]

Short names for a fixed set of values. Where a function asks for one of these, pass one of the values listed.

### WaxKind [#waxkind]

One of `"info"`, `"good"`, `"warn"`, `"bad"`.

### WaxCorner [#waxcorner]

One of `"top-left"`, `"top-right"`, `"bottom-left"`, `"bottom-right"`.

### WaxAnchor [#waxanchor]

One of `"top-left"`, `"top"`, `"top-right"`, `"left"`, `"center"`, `"right"`, `"bottom-left"`, `"bottom"`, `"bottom-right"`.

### WaxNav [#waxnav]

One of `"side"`, `"top"`.

### WaxFontFamily [#waxfontfamily]

One of `"ui"`, `"mono"`, `"plain"`.

### WaxThemeName [#waxthemename]

One of `"Midnight"`, `"Graphite"`, `"Abyss"`, `"Dune"`, `"Daylight"`, or any other `string`.

### WaxShape [#waxshape]

One of `"frame6"`, `"frame8"`, `"frame12"`, `"top8"`, `"glow12"`, `"glow12_soft"`, `"round2"`, `"round3"`, `"round4"`, `"round5"`, `"round6"`, `"round7"`, `"round8"`, `"round9"`, `"round10"`, `"round12"`.
