## WaxInstance [#waxinstance]

An engine object. Every class of the game ([`Actor`](/explorer?game=Actor), [`Pawn`](/explorer?game=Pawn), [`IcarusPlayerCharacter`](/explorer?game=IcarusPlayerCharacter) ...) is an Instance: it has what is listed here, and adds the properties and functions of its own class and of the classes that one is built on. A member the editor does not know is still read from the object, so nothing here stops you using it.

You get one from [`game.Highlight:GetAll`](/docs/reference/game#game-highlight-getall), [`game.wrap`](/docs/reference/game#game-wrap), [`game:Find`](/docs/reference/game#game-find), [`game:FindAll`](/docs/reference/game#game-findall), [`game:Library`](/docs/reference/game#game-library), [`game:GetTagged`](/docs/reference/game#game-gettagged), [`game:GetChildren`](/docs/reference/game#game-getchildren). Below, `instance` stands for one of these.

| `Parent` | [`WaxInstance?`](/docs/reference/game#waxinstance) | What GetParent() returns. |

## WaxHighlightMark [#waxhighlightmark]

One outlined actor.

You get one from [`game.Highlight:Add`](/docs/reference/game#game-highlight-add). Below, `mark` stands for one of these.

<InExplorer id="WaxHighlightMark" />

| Property | Type | Description |
| --- | --- | --- |
| `Instance` | [`WaxInstance`](/docs/reference/game#waxinstance) | An engine object. Every class of the game ([`Actor`](/explorer?game=Actor), [`Pawn`](/explorer?game=Pawn), [`IcarusPlayerCharacter`](/explorer?game=IcarusPlayerCharacter) ...) is an Instance: it has what is listed here, and adds the properties and functions of its own class and of the classes that one is built on. A member the editor does not know is still read from the object, so nothing here stops you using it. |
| `Active` | `boolean` | False once it was removed or its actor is gone. |

## WaxCreatureQuery [#waxcreaturequery]

Used by [`game.Creatures:GetAll`](/docs/reference/game#game-creatures-getall), [`game.Creatures:GetNearest`](/docs/reference/game#game-creatures-getnearest).

<InExplorer id="WaxCreatureQuery" />

| Field | Type | Description |
| --- | --- | --- |
| `within` (optional) | `number` | Only creatures this many metres away or nearer. The result is then sorted nearest first. |
| `from` (optional) | [`WaxInstance`](/docs/reference/game#waxinstance) \| `{ X: number, Y: number, Z: number }` | Where to measure from. Your character when omitted. |

## WaxHighlightOptions [#waxhighlightoptions]

Used by [`game.Creatures:Highlight`](/docs/reference/game#game-creatures-highlight), [`look:Set`](/docs/reference/game#look-set), [`mark:Set`](/docs/reference/game#mark-set), [`game.Highlight:Add`](/docs/reference/game#game-highlight-add), [`game.Highlight:Look`](/docs/reference/game#game-highlight-look).

<InExplorer id="WaxHighlightOptions" />

| Option | Type | Description |
| --- | --- | --- |
| `Color` | `string` \| `{ R: number, G: number, B: number }` | A name from game.Highlight.Colors, "#rrggbb", or values from 0 to 1. "Red" when omitted. |
| `Fill` | `boolean` | Also tints the whole model. True when omitted. |
| `FillColor` | `string` \| `{ R: number, G: number, B: number }` \| `false` | The tint's colour when it is not the outline's. false goes back to the outline's colour. |

## Named values [#named-values]

Short names for a fixed set of values. Where a function asks for one of these, pass one of the values listed.

### WaxCreature [#waxcreature]

A creature. Nearly all are an [`IcarusNPCCharacter`](/explorer?game=IcarusNPCCharacter). A few bosses are an [`IcarusPawn`](/explorer?game=IcarusPawn).

One of [`IcarusNPCCharacter`](/explorer?game=IcarusNPCCharacter) or [`IcarusPawn`](/explorer?game=IcarusPawn).

<InExplorer id="WaxCreature" />

### WaxGameMember [#waxgamemember]

One of `"World"`, `"GameInstance"`, `"GameState"`, `"GameMode"`, `"LocalPlayer"`, `"Character"`, `"Engine"`, `"Viewport"`, `"MapName"`, `"InProspect"`, `"Players"`, `"Creatures"`, `"Highlight"`, `"MapChanged"`.
