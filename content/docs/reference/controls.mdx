## Named values [#named-values]

Short names for a fixed set of values. Where a function asks for one of these, pass one of the values listed.

### WaxConsoleLine [#waxconsoleline]

One console line: the text, then an optional colour.

The same as `{ [1]: any, [2]: WaxColor? }`.
