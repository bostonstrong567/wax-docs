### `animation:Play(target?, options?)` [#animation-play]

Plays the animation. On a character or a creature its bone tracks move the bones, added to whatever the game is animating at that moment. On a thing of a blueprint or a part, its Self track moves the thing as a whole. On the player's own character it shows on the arms in first person and on the body in third. It costs nothing while nothing plays, and it stops when your mod unloads.

```lua
animation:Play(target?: any, options?: WaxAnimationPlayOptions): WaxAnimationPlay
```

| Parameter | Type | Description |
| --- | --- | --- |
| `target` (optional) | `any` | A character, a creature, a thing of a blueprint or a part. game.Me when omitted. |
| `options` (optional) | [`WaxAnimationPlayOptions`](/docs/reference/animations#waxanimationplayoptions) |  |

**Returns** [`WaxAnimationPlay`](/docs/reference/animations#waxanimationplay)

## WaxAnimationKey [#waxanimationkey]

One moment of a track. The first entry is the time in seconds, the second what is added at that time, the third how the way there is eased: "linear", "smooth", "in", "out" or "snap".

<InExplorer id="WaxAnimationKey" />

| Field | Type | Description |
| --- | --- | --- |
| any other key (`[1]`) | `number` | The time, in seconds from the start. |
| any other key (`[2]`) | [`WaxAnimationValues`](/docs/reference/animations#waxanimationvalues) | What is added to the bone or the thing at that time. |

## WaxAnimationSpec [#waxanimationspec]

What [`game.Animations:Define`](/docs/reference/animations#game-animations-define) makes an animation from.

Used by [`game.Animations:Define`](/docs/reference/animations#game-animations-define).

<InExplorer id="WaxAnimationSpec" />

| Field | Type | Description |
| --- | --- | --- |
| `tracks` | `table<string, WaxAnimationKey[]>` | What moves, by name: a bone ("RightShoulder", or the name its skeleton gives it), or Self for the thing as a whole. |
| `third` (optional) | `table<string, WaxAnimationKey[]>` | Tracks for the player's body seen in third person, when they should differ from tracks. |
| `length` (optional) | `number` | How long it runs, in seconds. The time of the last key when omitted. |
| `loop` (optional) | `boolean` | True starts it again when it ends. |
| `ease` (optional) | `"linear"` \| `"smooth"` \| `"in"` \| `"out"` \| `"snap"` | How keys are eased when a key does not say. "smooth" when omitted. |
| `events` (optional) | `{ [1]: number, [2]: fun(play: WaxAnimationPlay) }[]` | Functions that run when the animation passes a time. |
