## Blocked functions [#blocked-functions]

These UE4SS functions raise an error when a mod calls them. The reason is given for each one.

| Function | Note |

| `ExecuteAsync` | Blocked in Wax mods: it runs Lua on another thread, which corrupts the game's Lua state. Use [`task.spawn`](/docs/reference/tasks#task-spawn) or [`task.delay`](/docs/reference/tasks#task-delay). |
| `ExecuteWithDelay` | Blocked in Wax mods: it runs Lua on another thread, which corrupts the game's Lua state. Use [`task.spawn`](/docs/reference/tasks#task-spawn) or [`task.delay`](/docs/reference/tasks#task-delay). |
| `RegisterKeyBind` | Blocked in Wax mods: it runs Lua on another thread, which corrupts the game's Lua state. Use [`ui.Hotkey`](/docs/reference/ui#ui-hotkey). |
| `RegisterKeyBindAsync` | Blocked in Wax mods: it runs Lua on another thread, which corrupts the game's Lua state. Use [`ui.Hotkey`](/docs/reference/ui#ui-hotkey). |
| `RestartMod` | Blocked in Wax mods: restarting a UE4SS mod destroys the Lua state Wax runs in. Reload the mod through Wax instead. |
| `RestartCurrentMod` | Blocked in Wax mods: restarting a UE4SS mod destroys the Lua state Wax runs in. Reload the mod through Wax instead. |
| `UninstallMod` | Blocked in Wax mods: it destroys the Lua state Wax runs in. |
| `UninstallCurrentMod` | Blocked in Wax mods: it destroys the Lua state Wax runs in. |
