## How to read an entry

Each function has a line like this:

```lua
ui.Notify(text: any, options?: WaxNotifyOptions): WaxNotification
```

- The names in brackets are what you pass in. After each name comes the kind of value it takes.
- A `?` after a name means you may leave it out.
- What comes after the last `:` is what the function gives back.

Names that start with `Wax` are kinds of values that Wax defines. `WaxNotifyOptions` is a table of options,
and `WaxNotification` is the notification you get back. Click one to see what is in it.

## Dot or colon

- Use a dot for functions that stand on their own: `ui.Notify(...)`, `task.wait(1)`, `storage.Save(...)`.
- Use a colon for functions that act on one thing: `window:Button(...)`, `label:Set(...)`, `game:Find(...)`.

The reference shows each function the way you write it.

## The reference and your editor

The reference comes from the same definition files that give your editor its completion list. Both show the
same functions with the same descriptions.
