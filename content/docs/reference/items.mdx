## `game.Items` [#game-items]

The kinds of item the game has, and the facts of each. Nothing is read until you ask, and what was read is kept. An item is named by its row in D_ItemsStatic, such as "Wood" or "Stone_Pickaxe". Letter case, spaces, underscores and hyphens do not matter, so "stone pickaxe" names the same item.

Type name: `WaxItems`.

<InExplorer id="game.Items" />

### `game.Items:Share(total, item, stations)` [#game-items-share]

Deals `total` of an item out over the stations of one kind, as evenly as their room allows, so they all work at once: each gets up to the share that brings it level with the others, one that already holds more than its share gets nothing until the rest catch up, and what the even split leaves over goes to the first (the nearest, when the list is nearest first). ## WaxItemStack [#waxitemstack]

One stack in a slot of an inventory. Its fields are plain values, and changing them changes nothing in the game. Equip and Activate are functions: they tell the game to put this stack in a character's hand.

## WaxInventory [#waxinventory]

What Wax adds to every inventory: every Instance whose class is Inventory. A player's character has six of them, and other things that hold items have their own. Wax keeps a copy of an inventory that is asked about, so asking often costs little. It looks at the inventory again at most four times a second. When the weight or the number of slots is not what it was, every slot is read again. Otherwise a few slots are read in turn, so that all of them are read again within two seconds while you keep asking. An inventory that was not asked about for two seconds is read whole the next time. The game works a weight out a moment after the items change, so a new stack or a used-up one shows about a quarter of a second later, and what changes without the weight changing, such as durability or a stack moved to another slot, within two seconds. Refresh reads it all at once. Where the game itself tells Wax of a slot it changed, the copy follows at that moment and none of that waiting applies. That was seen for the inventories of a player's character on the host of a session. For a chest or a bench, and as a guest in someone else's game, it has not been tried, and there the looking above is what keeps the copy right. A field is nil, and a function raises an error that says so, when the game no longer keeps its inventories the way Wax reads them.

Below, `inventory` stands for one of these.

<InExplorer id="WaxInventory" />

| Property | Type | Description |
| --- | --- | --- |
| `Kind` | `string?` | What kind of inventory the game says it is: its row of D_InventoryInfo, such as "Backpack", "Quickbar" or "Equipment". It is asked of the game each time it is read. |
| `Size` | `integer?` | How many slots it has. #inventory is this number. |
| `Used` | `integer?` | How many of its slots hold something. |
| `Weight` | `number?` | What everything in it weighs, in kilograms. It is asked of the game each time it is read. |

| Signal | Handler receives | Description |
| --- | --- | --- |
| `ItemAdded` | `item`: `string`, `amount`: `integer`, `stack`: [`WaxItemStack?`](/docs/reference/items#waxitemstack) | Fires when the inventory holds more of an item than a frame before: the item's name as the game spells it, how many more, and a stack it went onto. It is told by the game, for every slot the game says it changed, so it only fires where the game tells of an inventory: see above. A stack that moves to another slot of the same inventory within a frame is not added. Connecting reads the inventory whole once. |
| `ItemRemoved` | `item`: `string`, `amount`: `integer`, `stack`: [`WaxItemStack?`](/docs/reference/items#waxitemstack) | Fires when the inventory holds fewer of an item than a frame before: the item, how many fewer, and a stack it came out of as that was before. |
| `ItemChanged` | `stack`: [`WaxItemStack?`](/docs/reference/items#waxitemstack), `previous`: [`WaxItemStack?`](/docs/reference/items#waxitemstack) | Fires for every slot that holds something else than a frame before: what it holds now, nil for nothing, and what it held. A tool that wore and a stack that moved are changes too. A spoil timer that only counts down is not. After a map change the handlers of all three are disconnected. |

## WaxPlayerItems [#waxplayeritems]

What Wax adds to a player's character for the things it carries: every Instance whose class is [`IcarusPlayerCharacter`](/explorer?game=IcarusPlayerCharacter) or is built on it, and game.Me. Each inventory is an Instance of the game's Inventory with what WaxInventory lists, and is nil when the character has no such inventory, as the character in the station has no backpack. An inventory Wax cannot read is left out of Count, Has and List.

Below, `playerItems` stands for one of these.

<InExplorer id="WaxPlayerItems" />

| Property | Type | Description |
| --- | --- | --- |
| `Backpack` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | The character's backpack: its BackpackInventory. |
| `Inventory` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | The character's backpack, the same value as Backpack. On a creature, Inventory stays the inventory the game keeps on it. |
| `Hotbar` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | The character's hotbar: its QuickbarInventory. hotbar[n] is hotbar:Slot(n), and #hotbar is how many slots it has. An empty slot is nil, so count from 1 to #hotbar to see every slot. |
| `ShipInventory` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | The cargo of the dropship assigned to this character, the hold the game calls DropShip_Equipment. nil while this character has no assigned dropship, as on the station. Count, Has and List on the character count the six inventories it carries; ask the ship with its own. Wax looks the ship up at most once a second. The hold the game calls Dropship_RemoveOnly is a different inventory. |
| `Equipment` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | What the character wears: its EquipmentInventory. |
| `Suit` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | The character's EnvirosuitInventory. |
| `Upgrades` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | The character's UpgradeInventory. |
| `Vision` | [`Inventory`](/explorer?game=Inventory) \| [`WaxInventory?`](/docs/reference/items#waxinventory) | The character's VisionInventory. |
| `HotbarSlot` | `integer?` | The slot of the hotbar the game says is in hand, counted from 1. The keys 1 to 9 and 0 are the slots 1 to 10, the box the game shows with G is slot 11, and with bare hands the game names slot 12. nil when the game names none, as it does for a moment after the item in hand is used up. |
| `HeldItem` | [`WaxItemStack?`](/docs/reference/items#waxitemstack) | What sits in that slot of the hotbar, or nil when it is empty. With bare hands it is the game's own item Player_Fist. It is as fresh as the hotbar's copy: see WaxInventory. |

## WaxItemFacts [#waxitemfacts]

What a kind of item is, from the game's own tables. The table is yours: changing it changes nothing in the game.

Returned by [`game.Items:Get`](/docs/reference/items#game-items-get). Used by [`game.Items:Get`](/docs/reference/items#game-items-get), [`inventory:Count`](/docs/reference/items#inventory-count), [`inventory:Has`](/docs/reference/items#inventory-has), [`inventory:Where`](/docs/reference/items#inventory-where), [`inventory:Give`](/docs/reference/items#inventory-give), [`inventory:Take`](/docs/reference/items#inventory-take), [`inventory:Push`](/docs/reference/items#inventory-push), [`inventory:Pull`](/docs/reference/items#inventory-pull) and others.

<InExplorer id="WaxItemFacts" />

| Field | Type | Description |
| --- | --- | --- |
| `Name` | `string` | The item's name: its row in D_ItemsStatic, spelled as the game spells it. |
| `DisplayName` | `string` | The name the game shows players, in the language the game was showing when it was read. The item's own name when the game shows none. |
| `Description` | `string?` | The game's description of the item. nil when it has none. |
