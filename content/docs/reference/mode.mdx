## `game.Mode` [#game-mode]

How this copy of the game runs, game.Mode. It is read when Wax starts and again when the map changes.

Type name: `WaxMode`.

<InExplorer id="game.Mode" />

| Member | Type | Description |
| --- | --- | --- |
| `kind` | `"server"` \| `"host"` \| `"client"` \| `"single"` | "server": a dedicated server, with no screen and nobody at the keyboard. "host": a player hosting a world from the game. "client": joined someone else's world. "single": alone. |
| `IsServer` | `boolean` | True on a dedicated server. |
| `IsAuthority` | `boolean` | True where the session's rules run: a dedicated server, a host, or alone. False for a client. |
| `HasScreen` | `boolean` | False on a dedicated server, where there is no interface: `ui` is nil there, and nothing of a mod can be shown or pressed. True in a game, from its first frame. |

| Signal | Handler receives | Description |
| --- | --- | --- |
| `Changed` | `kind`: `string`, `before`: `string` | Fires after a map change when the kind is not what it was, with the new kind and the one before. |
