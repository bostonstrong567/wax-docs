## `game.Effects` [#game-effects]

game.Effects: the game's particle effects, lights, glowing trails and camera shakes, on anything. Everything a mod started is taken away when the mod unloads. Nothing costs anything while no effect is alive.

Type name: `WaxEffects`.

## WaxTrailOptions [#waxtrailoptions]

What [`game.Effects:Trail`](/docs/reference/effects#game-effects-trail) takes besides what it follows.

Used by [`game.Effects:Trail`](/docs/reference/effects#game-effects-trail).

<InExplorer id="WaxTrailOptions" />

| Option | Type | Description |
| --- | --- | --- |
| `from` | `{ X: number, Y: number, Z: number }` \| `number[]` | One end of the edge that leaves the trail, measured from what it follows. |
| `to` | `{ X: number, Y: number, Z: number }` \| `number[]` | The other end. \{ 0, 0, 50 \} when omitted. |
| `color` | `string` \| `table` | Red when omitted. |
| `seconds` | `number` | How long the ribbon is, in time. 0.25 when omitted. |
| `life` | `number` | How long it runs. Until it is stopped when omitted. |
| `width` | `number` | Makes it a streak this wide along the middle of the edge, always turned to face the view. Without it the ribbon lies between the edge's two ends, and a cut that comes straight at the view shows it from the side, as a line. |
| `with_view` | `boolean` | True keeps the trail with the view, as the arms of first person are, instead of leaving it behind in the world. For something held in first person. |
| `delay` | `number` | It starts this many seconds from now. A swing winds up first, and a trail that only runs during the cut is one clean arc. `life` counts from when it starts. |
| `embers` | `number` \| `{ rate?: number, size?: number, life?: number, speed?: number, rise?: number }` | Small glowing bits that come off the edge while it moves: how many a second, or a table. They drift, rise and shrink to nothing. None when omitted. |
| `material` | [`WaxInstance`](/docs/reference/game#waxinstance) | A material of your own in place of the plain glowing one, from [`game.Assets:Material`](/docs/reference/assets#game-assets-material). A thing held in first person is drawn bent toward the screen by its material, and a trail only lies on it when its material bends the same way. |
