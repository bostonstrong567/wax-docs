## WaxCreatureMembers [#waxcreaturemembers]

What Wax adds to a creature: every Instance whose class is [`IcarusNPCCharacter`](/explorer?game=IcarusNPCCharacter) or [`IcarusPawn`](/explorer?game=IcarusPawn), or is built on one of them. Each field asks the game when it is read. A field is nil when the creature has no such value. Epic, Behaviour, Action, Target, Stance and IsFrozen are read from an [`IcarusNPCCharacter`](/explorer?game=IcarusNPCCharacter) only. On the few creatures that are an [`IcarusPawn`](/explorer?game=IcarusPawn) they are nil. The host can assign Behaviour and call SetLevel, Freeze, Unfreeze, Attack and Remove. They act on the machine that runs them, so in someone else's game each of them raises an error that says only the host can. game.IsHost says which you are. In this version of Wax they are for wild animals that are an [`IcarusNPCCharacter`](/explorer?game=IcarusNPCCharacter). On a tamed animal and on an [`IcarusPawn`](/explorer?game=IcarusPawn) each raises an error that says so, because the game's calls were only made on wild ones. No other field can be assigned. A creature that is an [`IcarusNPCCharacter`](/explorer?game=IcarusNPCCharacter) is a character as well, so it also has what every character has: Health, Level, Alive, Heal, Kill, Teleport, Damaged, Died and the rest.

Below, `creature` stands for one of these.

<InExplorer id="WaxCreatureMembers" />

| Property | Type | Description |
| --- | --- | --- |
| `Kind` | `string?` | Its kind as the game's data names it, such as "Wolf". "Unknown" when the game's data does not say what it is. |
| `Variant` | `string?` | The version of its kind, such as "Conifer_Wolf": a row of the table D_AISetup. nil when the game names none. |
| `DisplayName` | `string?` | The name the game shows players for its kind, such as "Cave Worm". |
| `Epic` | `string?` | The row of D_EpicCreatures that makes it a named boss or alpha, such as "AlphaWolf_Boss". nil for an ordinary creature. |
| `Behaviour` | `string?` | The team the game has it on now, which decides whom it treats as an enemy: "Friendly" for the team FriendlyAll, "Tame" for Player (the players' own team), "HostileToPlayers" for EnemyPlayerOnly, "HostileToAll" for EnemyAll. On any other team it is "Default" while that is the team its variant starts on, and else the team's own name, a row of D_AIRelationships such as "DefaultLargeCarnivore". nil when the game names no team. The host can assign it: one of the five words, where "Default" puts it back on the team its variant starts on, or a team's own name. A name that is neither raises an error that suggests the nearest. The game goes by the new team from the next time the animal notices somebody, not at once: a wolf that had a player in view attacked two seconds after "HostileToPlayers", a wolf that was walking away did nothing in five, and an animal that is attacking goes on attacking after "Friendly". |
| `Action` | `string?` | What it is doing now, as the game's class for that action is called: "Wander", "FindFood", "EmergeFromRetreat". nil while the game names none for it. |
| `Target` | [`WaxInstance?`](/docs/reference/game#waxinstance) | The actor it is after right now, such as a player's character or another creature. nil while it is after nothing. |
| `Stance` | `"Standing"` \| `"Sitting"` \| `"Lying"` \| `nil` | How it holds itself. |
| `IsJuvenile` | `boolean?` | True for a young animal: one that a taming rule of the game, a row of D_Tames, names as the young of its kind. nil when the game's tables cannot be read. |
| `IsTamed` | `boolean` | True for an animal that has been tamed: a mount, a pet or livestock. The game makes these from classes built on [`IcarusMountCharacter`](/explorer?game=IcarusMountCharacter), and that is what is looked at. A speeder bike counts as one, because the game builds it the same way. |
| `CanBeTamed` | `boolean?` | True when a taming rule of the game names its variant, as the young animal or as the grown one, and it is not tamed already. It says what the game's data has, not whether a taming would work right now. nil when the game's tables cannot be read. |
| `IsFrozen` | `boolean?` | True while the creature is held frozen, by Freeze or by the game itself. nil on a creature whose class has no such flag. |

### `creature:SetLevel(level)` [#creature-setlevel]

Sets the creature's level through the game, for the host only. Its experience, the most health it can have and its level stats follow in the same call, and its health is full afterwards. So set the level first and Health after it.

```lua
creature:SetLevel(level: number): boolean
```

| Parameter | Type | Description |
| --- | --- | --- |
| `level` | `number` | From 1 to 120, the highest level the game's own zones give. It is rounded to a whole number. |

**Returns** `boolean` (`changed`) True when the level changed. False when the creature had that level already.

### `creature:Freeze()` [#creature-freeze]

Holds the creature where it stands, for the host only. It stops in the same frame and decides nothing until Unfreeze.

```lua
creature:Freeze(): boolean
```

**Returns** `boolean` (`frozen`) True when it moved freely and is frozen now. False when it was frozen already.

<InExplorer id="WaxCreatureMembers.Freeze" />

### `creature:Unfreeze()` [#creature-unfreeze]

Lets a frozen creature go again, for the host only. A deer walked on within half a second.

```lua
creature:Unfreeze(): boolean
```

**Returns** `boolean` (`freed`) True when it was frozen and is free now. False when it was not frozen.

<InExplorer id="WaxCreatureMembers.Unfreeze" />

### `creature:Attack(target)` [#creature-attack]

Makes the creature angry at a player's character, for the host only: the game raises its aggression to the most and tells it where the target is. A wolf had the character as its Target within a second or two and ran at it. It is for the animals the game gives aggression, the hunters. For one that has none, such as a deer or a rabbit, it raises an error that says so, and so it does for a target that is not a player's character. Nothing in Wax calls an attack off again. Remove takes the animal away.

```lua
creature:Attack(target: IcarusPlayerCharacter|WaxMe): boolean
```

| Parameter | Type | Description |
| --- | --- | --- |
| `target` | [`IcarusPlayerCharacter`](/explorer?game=IcarusPlayerCharacter) \| [`WaxMe`](/docs/reference/character#game-me) | The player's character to go for, or game.Me. |

**Returns** `boolean` (`angry`) True when its aggression is raised afterwards.

<InExplorer id="WaxCreatureMembers.Attack" />

### `creature:Remove()` [#creature-remove]

Takes the creature out of the world, for the host only, alive or dead, with nothing left behind. The game does it a moment later, not in the same frame: IsValid() says when it is gone. The game replaces a dead creature by a corpse a few seconds after its death, one to three seconds when it was timed. The corpse is no creature: it is not in game.Creatures, and Remove raises an error on the creature it was, which is gone by then. A dead creature that was removed before that left no corpse.

```lua
creature:Remove(): boolean
```

**Returns** `boolean` (`asked`) Always true.

## WaxSpawnOptions [#waxspawnoptions]

What [`game.Creatures:Spawn`](/docs/reference/game#game-creatures-spawn) takes besides the kind and the place.

Used by [`game.Creatures:Spawn`](/docs/reference/game#game-creatures-spawn).

<InExplorer id="WaxSpawnOptions" />

| Option | Type | Description |
| --- | --- | --- |
| `level` | `number` | The creature's level, from 1 to 120. When omitted, the middle level the game's data gives creatures in the zone the place lies in, and 1 where the game names no zone. |
| `variant` | `string` | Which variant of the kind, such as "Snow_Wolf", when the first value names a kind that has several. |
| `facing` | `{ Yaw: number }` | Which way it looks, in degrees. When omitted, a creature put in front of your character looks at it, and one put at a place you gave faces as the game makes it. |
| `behaviour` | `string` | The team to put it on once the game has finished making it: what a creature's Behaviour can be assigned. |
| `keep` | `boolean` | False takes the creature out of the world again when the mod that spawned it unloads. True when omitted: what a mod spawned stays. |
