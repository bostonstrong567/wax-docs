## `task` [#task]

Runs functions as tasks: now, at the end of the frame, after a time, or again and again. A task can pause with [`task.wait`](/docs/reference/tasks#task-wait), and the game goes on while it waits.

Type name: `WaxTask`.

### `task.every(seconds, f, ...)` [#task-every]

<NextMark block />

Runs f(...) again and again: the first time after `seconds`, then `seconds` after each run has ended. It never runs more than once a frame. An error in f is reported and the runs go on. After five errors in a row they stop. It stops when the mod unloads, and [`task.cancel`](/docs/reference/tasks#task-cancel) stops it.

```lua
task.every(seconds: number, f: function, ...: any): thread
```

| Parameter | Type |
| --- | --- |
| `seconds` | `number` |
| `f` | `function` |
| `...` | `any` |

**Returns** `thread`

<InExplorer id="task.every" />

## WaxSignal [#waxsignal]

An event that handlers connect to. `F` is the shape of a handler, as in `WaxSignal<fun(name: string)>`.

You get one from [`instance:GetAttributeChangedSignal`](/docs/reference/game#instance-getattributechangedsignal), [`instance:GetPropertyChangedSignal`](/docs/reference/game#instance-getpropertychangedsignal), [`Signal.new`](/docs/reference/tasks#signal-new). Below, `signal` stands for one of these.
