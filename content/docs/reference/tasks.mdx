## WaxConnection [#waxconnection]

What Connect returns: one handler's link to a signal.

You get one from [`signal:Connect`](/docs/reference/tasks#signal-connect), [`signal:Once`](/docs/reference/tasks#signal-once). Below, `connection` stands for one of these.

| Property | Type | Description |
| --- | --- | --- |
| `Connected` | `boolean` | False once the handler has been disconnected. |

### `connection:Disconnect()` [#connection-disconnect]

Stops the handler from being called again.

```lua
connection:Disconnect()
```

**Returns** nothing.

## WaxSignal [#waxsignal]

An event that handlers connect to. `F` is the shape of a handler, as in `WaxSignal<fun(name: string)>`.

You get one from [`instance:GetAttributeChangedSignal`](/docs/reference/game#instance-getattributechangedsignal), [`Signal.new`](/docs/reference/tasks#signal-new). Below, `signal` stands for one of these.

### `signal:Connect(fn)` [#signal-connect]

Calls fn on every Fire, newest connection first.

```lua

```

| Parameter | Type |
| --- | --- |
| `fn` | `F` |

**Returns** [`WaxConnection`](/docs/reference/tasks#waxconnection)

### `signal:Once(fn)` [#signal-once]

Like Connect, for the next Fire only.

```lua

```

| Parameter | Type |
| --- | --- |
| `fn` | `F` |

**Returns** [`WaxConnection`](/docs/reference/tasks#waxconnection)

### `signal:Wait()` [#signal-wait]

Pauses the calling task until the next Fire and returns what was fired.
