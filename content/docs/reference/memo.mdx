## WaxMemoModule [#waxmemomodule]

Small caches for hot paths: a frame memo forgets everything when the frame changes, a timed one forgets an entry after its seconds. A hook the game calls hundreds of times a frame answers the same question from one of these after the first time.

Below, `memo` stands for one of these.

<InExplorer id="WaxMemoModule" />

### `memo.frame()` [#memo-frame]

A cache that holds its entries for the rest of the current frame.

```lua
memo.frame(): WaxMemo
```

**Returns** [`WaxMemo`](/docs/reference/memo#waxmemo)
