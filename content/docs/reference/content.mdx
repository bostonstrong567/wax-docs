## WaxContent [#waxcontent]

The game content a mod brings: models, textures, materials, sounds and blueprints made in the Unreal editor and packed into one file, content/\<Id>.pak, in the mod's folder. Wax checks the file, hands it to the game before the mod's code runs, and the mod then loads from it by name. `mod.Content` is nil for a mod without that file. A changed pak is taken up without a restart when the mod reloads: the game lets go of the older copy and loads from the newer one. An asset the game still uses at that moment keeps its older look until the game is restarted, and State then says "restart".

Below, `content` stands for one of these.

<InExplorer id="WaxContent" />

| Property | Type | Description |
| --- | --- | --- |
| `State` | `"ready"` \| `"restart"` \| `"off"` | "ready": the content is there. "restart": it is there, and some assets still show an older copy until the game is restarted. "off": the game does not have it, and Reason says why. |
| `Reason` | `string?` | Why State is "off" or "restart". Nil when it is "ready". |
| `Files` | `string[]` | The files in the pak, such as "BP_Thing.uasset". A new list each time. |

### `content:Path(name)` [#content-path]

The game's path of an asset in this mod's content, as [`game.Assets:Load`](/docs/reference/assets#game-assets-load) takes it. "Meshes/Rock" gives "/Game/Mods/\<Id>/Meshes/Rock.Rock".

```lua
content:Path(name: string): string
```

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | `string` | The asset's name, with its folders inside the mod's content when it has any. |

**Returns** `string`

### `content:ClassPath(name)` [#content-classpath]

The game's path of a blueprint's class in this mod's content: "BP_Thing" gives "/Game/Mods/\<Id>/BP_Thing.BP_Thing_C". It is what `base` of [`game.Blueprints:Define`](/docs/reference/blueprints#game-blueprints-define) takes.

```lua
content:ClassPath(name: string): string
```

| --- | --- | --- |

### `content:Load(name)` [#content-load]

Loads an asset of this mod's content and keeps it for the mod, as [`game.Assets:Load`](/docs/reference/assets#game-assets-load) does.

```lua
content:Load(name: string): WaxInstance?, string?
```

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | `string` | The asset's name, such as "T_Icon" or "Meshes/Rock". |

**Returns**

- [`WaxInstance?`](/docs/reference/game#waxinstance) (`asset`) Nil when it could not be loaded.
- `string?` (`why`) The reason, when it could not.
