A mod is made of plain text files. Any text editor works.

For more comfort there is an extension for Visual Studio Code, called **Wax for Icarus**.

<Callout type="warn" title="Still being written">
  The extension is in development, like Wax itself. It is not released yet. This page stays short until it is.
</Callout>

## What the extension gives you

- **Completion.** Type `ui.` and pick from a list of everything `ui` offers. Each entry comes with a short description.
- **A New Mod command.** It makes the folder and the first files for you.
- **Run in game.** Send the code you are working on to the running game.
- **The log.** See what your mod printed without leaving the editor.

## Without the extension

You do not need it to write mods.

- Saving a file reloads your mod. That is [hot reload](/docs/hot-reload), and it works with any editor.
- The log is on the **Log** page of the [Wax panel](/docs/debug-panel), inside the game.
- The command bar on that page completes names when you press **Tab**.
- Every function is described in the [reference](/docs/reference).
