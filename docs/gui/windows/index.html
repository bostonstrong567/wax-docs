Windows

Make a window, give it pages, and add a status bar.

A window is a box in the menu that holds your controls.

Switch the mod on, then press the key of your mod's windows to see it. Wax tells you once which key that is, and it is on the mod's card of the Mods page as Show / hide. The title bar has a button to roll the window up, and a cross to close it. The user can drag the window by its title bar and resize it by any edge or corner. The bottom right corner shows a grip.

Everything you add with window:Something(...) is a control. The Controls page lists them all.

Give each window its own title

Wax remembers a window's place and size by its title. Two windows of one mod with the same title would share one place.

ui.Windows() gives a list of every window in the menu.

Resizing

The player resizes a window by dragging any of its four edges or four corners. You do nothing for it: every window has it.

  • The mouse pointer changes over an edge or a corner, and that piece of the window's outline lights up. It is brighter while it is held. The bottom right corner also shows a grip.
  • The edge across from the one that is dragged stays where it is.
  • Resizing stops at the window's smallest size and at the edges of the screen.
  • A window rolled up to its title bar cannot be resized.
  • Wax remembers the size, as it remembers the place.

The smallest size is 240 by 140 for a plain window. A window with side pages is never narrower than 420, and one with tabs along the top never lower than 200 or narrower than its tabs need.

resizable = false makes a window that is always the size you give it. It has no grip, its edges and corners do nothing, and a size remembered from before is not used. window:SetSize still works.

Lay your controls out so that they work at any size the player picks. Controls fill the width they are given, a Row shares it, and a page scrolls when the window is too low for it.

One key for your mod's windows

All windows of your mod come up together, with one key, and go away with it. Other mods' windows and the Wax panel stay as they are. Ask for the key with the key option of your first window. Without it Wax gives your mod a free key and tells the player once.

The player can change the key on your mod's card of the Mods page. The menu says how to read and set it from code.

Pages down the side

Give a window nav = "side" and it gets a list of pages on the left. window:Page adds a page. Add controls to the page, not to the window.

The first page you add is the one that shows first. The user can drag the line beside the list to make the list wider.

Pages along the top

With nav = "top" the pages become tabs. The tabs are all the same width, and the window cannot be made narrower than its tabs need.

Page options and functions

Option of window:Page(name, options)What it does
iconAn icon shown before the page's name.
bottomtrue lists the page at the foot of a side list. Good for a settings page.
scrollfalse makes a page that does not scroll. A Grid or Console on it then fills the space that is left.
FunctionWhat it does
window:Page(name, options)Adds a page and gives it back.
window:SelectPage(name)Switches to the page with that name.
window:RemovePage(page)Removes a page and everything on it.
window:SetNavWidth(width)Sets the width of the side list.

If you add a control straight to a window that has pages, Wax puts it on a first page called Main.

Load more when the user reaches the end

A page has a signal called NearEnd. It fires when the user scrolls close to the bottom. Use it to add more as the user scrolls.

NearEnd also fires a few times a second while the page is not full yet. So do nothing when there is no more to add, as the first line of add_more does.

For very long lists, use a Grid instead.

A status bar

window:StatusBar() adds a line along the bottom of a window. Use it to say what your mod is doing.

FunctionWhat it does
status:Set(text, options)Shows a message. kind sets the colour: "info", "good", "warn" or "bad". icon adds an icon.
status:Busy(text)Shows a message with a spinning circle, until the next Set.
status:Progress(amount)Shows a thin line across the bar, from 0 to 1. nil hides it.
status:Right(text)Shows text at the right-hand end.
status:Clear()Empties the message and hides the line.
