Controls

Every control you can put in a window, with a picture and an example for each.

A control is one thing in a window: a line of text, a button, a switch, a slider.

You add a control by calling a function on a container. A window is a container. So is a page, a section, a row and an overlay. They all have the same functions.

Every example with the file name init.lua above it is a whole file. Paste it, save, and press the key of your mod's windows. It is on the mod's card of the Mods page, as Show / hide.

How controls tell you things

Most controls take a function that runs when the user changes them.

Every control also has a Changed signal. It does the same thing, and you can connect to it later or more than once.

  • Your function may call task.wait. It runs as a task.
  • Changing a control from code with Set does not run your function. Only a change by the user does.

What every control can do

FunctionWhat it does
control:SetVisible(shown)Shows or hides the control. A hidden control takes no room.
control:SetEnabled(enabled)false greys the control out and stops it reacting.
control:Destroy()Removes the control.

Text

Label

container:Label(text, options) adds text. Long text wraps to the width of the container. In a row a label is one line: see Text that has to fit.

OptionWhat it does
dimtrue uses the theme's dimmer text colour.
colorA colour of your own. Make one with ui.Color("#RRGGBB"), or take one from ui.Theme().
sizeThe text size.
faceThe weight of the game's interface font, such as "Book", "Medium" or "Bold".
family"ui" for the game's interface font (the usual one), "mono" for a fixed-width font, or "plain".
FunctionWhat it does
label:Set(value)Replaces the text.
label:SetColor(color)Changes the text colour.

Heading

container:Heading(text) adds a bold title line for a group of controls. heading:Set(value) replaces the text.

Title

container:Title(text, description) adds a title for a whole page: large text, an optional line of explanation, and a rule under it.

Separator

container:Separator() adds a thin dividing line.

Spacer

container:Spacer(height) adds an empty gap. Leave the height out to get the theme's normal gap.

Button

container:Button(caption, on_click, options) adds a button. on_click runs on each click.

Pass nil as the caption and give an icon to get a small icon button.

OptionWhat it does
primarytrue draws the button in the accent colour. Use it for the main action.
iconAn icon shown before the caption.
spintrue turns the icon round once on every click. It shows that the click started something.
stretchA button with a caption fills the width. false makes it only as wide as its caption. An icon button is small. true makes it fill the width.
sizeFor an icon button: the side of the square it is drawn as, such as 24 for a line that is lower than a button. Left out, it is as tall as the other buttons. New in Wax 0.3.0.
tipHelp shown beside the mouse once it has rested on the button. Give one to every button that is only an icon.
FunctionWhat it does
button:SetIcon(name)Shows another icon. The button must have been made with one.
button:Spin()Turns the icon round once.
button:SetCaption(text)Replaces the caption. The button must have been made with one.
button:SetTip(tip)Changes the help shown while the mouse rests on the button. nil takes it away.
SignalFires when
button.ActivatedThe button is clicked. button.Changed is the same signal.

Icon

container:Icon(name, options) adds an icon on its own. Find names on the Icons page of the Wax panel.

OptionWhat it doesWhen left out
sizeThe size of the icon.20
colorThe colour of the icon.The theme's text colour.

icon:Set(name) shows another icon.

Toggle

container:Toggle(caption, initial, on_change) adds a switch. initial is true for on. on_change gets true or false.

FunctionWhat it does
toggle:Get()true while the switch is on.
toggle:Set(on)Turns the switch on or off.
SignalFires whenYour function gets
toggle.ChangedThe user flips the switch.true or false.

Slider

container:Slider(caption, options, on_change) adds a slider with a number beside it. The user can drag the handle, or click the number and type a value.

OptionWhat it doesWhen left out
minThe lowest value.0
maxThe highest value.1
valueThe value to start at.The same as min.
stepValues snap to steps of this size, counted from min.No snapping.
formatHow the number is written, as a string.format pattern."%.2f", or "%d" with a step of 1 or more.
stackedtrue puts the caption above the track, false beside it.Beside it when there is room, above when there is not.
livefalse reports the value once, when the mouse lets go. Use it when a change is slow to apply.true
FunctionWhat it does
slider:Get()The value right now.
slider:Set(value)Moves the slider. The value is snapped and kept inside the range.
SignalFires whenYour function gets
slider.ChangedThe value changes while dragging, or a number is typed.The value.
slider.ReleasedThe user lets go of the handle.The value.

Input

container:Input(caption, options, on_commit) adds a text box. on_commit runs when the user presses Enter, or clicks somewhere else. Pass nil as the caption for a box without one.

OptionWhat it does
textThe text to start with.
hintGrey text shown while the box is empty.
stackedtrue puts the caption above the box, false beside it. Left out, it goes beside the box when there is room, above when there is not.
monotrue uses a fixed-width font. Good for code.
FunctionWhat it does
input:Get()The text in the box right now.
input:Set(text)Replaces the text.
input:Focus()Puts the typing cursor in the box, so the user can type without clicking it.
input:HasFocus()true while the typing cursor is in the box.
input:SetGhost(text)Shows grey text after what is typed, such as the rest of a suggested word. Only a box made with mono = true shows it.
SignalFires whenYour function gets
input.ChangedThe user finishes typing: Enter, or the box loses the cursor.The text.
input.EnteredEnter is pressed. It fires even when the text is the same as last time.The text.
input.TypedThe text changes while typing. Every letter.The text.

Dropdown

container:Dropdown(caption, choices, selected, on_change) adds a list the user picks one choice from.

  • choices is a list of values.
  • selected is the one chosen at the start. Left out, it is the first.
  • on_change gets the choice the user picked.

The list opens in place, under its header. The chosen row is highlighted. Only one list is open in a window at a time. A long list scrolls.

FunctionWhat it does
dropdown:Get()The selected choice.
dropdown:Set(choice)Selects a choice.
SignalFires whenYour function gets
dropdown.ChangedThe user picks a choice.The choice.

Color

A colour the user can change. The row shows the colour and its code. A click opens a panel under it with a box of shades, a bar of hues, and the code as text.

The value is a string such as "#ff7a00".

  • Drag in the box to pick a shade, and along the bar to pick a hue.
  • Type or paste a code into the text box and press Enter. The button beside it copies the code.
  • A click anywhere else closes the panel.
Function or signalWhat it does
look:Get()The colour as "#rrggbb".
look:Set(color)Sets the colour. It does not call your function.
look.ChangedFires with every change, also while the mouse is held down.
look.ReleasedFires once when the user lets go. Use it for saving.

Keybind

container:Keybind(caption, key, on_change) adds a key the user can change. The user clicks the button, then presses a key. Escape cancels.

on_change gets the name of the new key, such as "M" or "F5". That name is what ui.Hotkey takes, so the two work together.

FunctionWhat it does
keybind:Get()The key's name, or nil when none is set.
keybind:Set(key)Sets the key.
SignalFires whenYour function gets
keybind.ChangedThe user picks a new key.The key's name.

Progress

container:Progress(caption, value, options) adds a bar. value goes from 0 (empty) to 1 (full). The percentage is written beside the caption.

OptionWhat it doesWhen left out
colorThe colour of the filled part.The accent colour.
FunctionWhat it does
progress:Get()The value, from 0 to 1.
progress:Set(value)Moves the bar.
progress:SetColor(color)Changes the colour of the filled part.

Field

container:Field(name, value, options) adds a name with a value on the right. Use it to show facts.

OptionWhat it does
monotrue shows the value in a small fixed-width font. Good for numbers that keep changing, because the text does not shift as they change.
FunctionWhat it does
field:Set(value)Replaces the value.
field:SetColor(color)Changes the colour of the value.

Section

container:Section(title, options) adds a card with a title. The user clicks the title to open and close it.

A section is a container. Add controls to the section, as you would to a window.

OptionWhat it does
openfalse starts the section closed.
collapsiblefalse makes a plain titled group that is always open.
fittrue keeps the title on one line. A title too long for the card is cut short with three dots, and shown whole as a tip while the mouse rests on it. Without it a long title wraps. New in Wax 0.3.0.
FunctionWhat it does
section:SetOpen(open)Opens or closes the section.
section:IsOpen()true while it is open.

To hide, disable or remove the whole card, use section.control:

Row

container:Row() adds a row. Controls you add to the row sit side by side and share the width.

A row is a container too. row.control is the row itself, for SetVisible, SetEnabled and Destroy.

Flow

container:Flow(options) adds an area where controls keep their own size. When a line is full, the next control goes onto a new line.

OptionWhat it does
cellMakes it a grid instead. Every control gets the same width, at least this wide, and each line is full.

Console

container:Console(options) adds a scrolling box of text lines, such as a log. The user can drag across the lines to select them, and copy with Ctrl+C.

Each line is a small table: the text, then an optional colour.

OptionWhat it doesWhen left out
heightThe height of the box.220
maxHow many lines are shown at most. Older lines drop off the top.150
FunctionWhat it does
console:SetLines(lines)Shows these lines.
console:GetText()Everything being shown, as one piece of text. Pass it to ui.Copy to put it on the clipboard.
console:SetFollow(on)true scrolls to the newest line on every SetLines. It starts on.

Text that has to fit

Text that has one line to itself does not spill out of its box. When it is too long, it is cut short with three dots, and the whole text shows as a tip while the mouse rests on it. This happens by itself for:

  • the caption of a button,
  • the header of a dropdown,
  • a label in a row,
  • the title of a section made with fit = true.

A label that is not in a row wraps onto more lines, as before.

For text you place yourself, two functions measure it:

FunctionWhat it gives
ui.TextWidth(text, options)How wide a line of text is drawn, in the units windows are sized in. It is right to within a few percent.
ui.Shorten(text, width, options)The text if it fits in that width, else its start with three dots after it. A second value is true when it was cut.

options may hold size, face ("Bold", "Book" or "Medium") and family = "mono", as a label takes them.

Slots

A block of square cells that each show a picture, as an inventory does. It is described with panels: Slots.

Model

A box that shows a creature of the game in 3D. It has its own page: 3D models.

Grid

A grid shows a long list in cells of the same size. It builds only the cells you can see, so a list of thousands of items is fine. It has its own page: Grid.
